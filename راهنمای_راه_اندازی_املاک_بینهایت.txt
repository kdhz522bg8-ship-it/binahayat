املاک بینهایت — راه‌اندازی مرحله‌ای فضای ابری
================================================

فایل اصلی:
Amلاک_بینهایت_روشن_V2.html

فایل تنظیمات ابری:
supabase_setup_emlak_binahayat.sql

مرحله ۱ — ساخت پروژه
--------------------
1) وارد Supabase شو.
2) یک پروژه جدید بساز.
3) بعد از ساخت پروژه، از Project Settings > API آدرس Project URL و Publishable Key (یا anon key در پروژه‌های قدیمی) را بردار.
4) service_role/secret key را داخل HTML نگذار.

مرحله ۲ — ساخت دیتابیس
----------------------
1) داخل Supabase برو به SQL Editor.
2) فایل supabase_setup_emlak_binahayat.sql را باز کن.
3) تمام متن آن را Copy کن.
4) داخل SQL Editor Paste کن.
5) Run بزن.
6) باید جدول public.app_data و bucket مربوط به property-files ساخته شوند.

مرحله ۳ — اتصال برنامه
-----------------------
1) فایل Amلاک_بینهایت_روشن_V2.html را باز کن.
2) وارد بخش ☁️ ابر شو.
3) در «تنظیم اتصال Supabase»:
   - Supabase Project URL را وارد کن.
   - Publishable/anon key را وارد کن.
4) «ذخیره اتصال» را بزن.
5) «تست اتصال» را بزن.
6) اگر اتصال آماده بود، با ایمیل ثبت‌نام کن و سپس وارد شو.

مرحله ۴ — تست ذخیره ابری
------------------------
1) یک مشتری یا فایل آزمایشی بساز.
2) برو به ☁️ ابر.
3) «ارسال به ابر» را بزن.
4) در یک مرورگر/دستگاه دیگر با همان حساب وارد شو.
5) «دریافت از ابر» را بزن.
6) اطلاعات باید برگردد.

نکته مهم
---------
نسخه فعلی داده‌های اصلی برنامه را در app_data به صورت JSON ذخیره می‌کند.
برای فایل‌های حجیم، نسخه بعدی باید آپلود واقعی عکس/PDF/قرارداد را مستقیماً در Storage انجام دهد و فقط آدرس و مشخصات فایل را در app_data نگه دارد.

آموزش هوش مصنوعی
----------------
برای اینکه آموزش‌ها واقعاً «زیر نظر هوش مصنوعی» باشند، API Key هوش مصنوعی نباید داخل HTML قرار بگیرد.
معماری امن:
HTML → Supabase Edge Function → سرویس هوش مصنوعی

در نسخه آموزشی، هوش مصنوعی باید پاسخ‌ها را با مثال‌های واقعی املاک، ویلا، مشتری، فایل، مذاکره، قرارداد، پیج و فروش تولید کند.
