املاک بینهایت V8 — Offline First + Smart Matching
1) فایل‌های index.html، manifest.webmanifest و sw.js را در ریشه GitHub Pages جایگزین نسخه قبلی کن.
2) setup.sql را در Supabase > SQL Editor اجرا کن.
3) آدرس Supabase و Publishable Key داخل index.html از پروژه فعلی کاربر تنظیم شده‌اند.
4) یک بار سایت را با اینترنت باز کن تا Service Worker نصب و خود برنامه cache شود؛ بعد از نصب می‌توانی تست آفلاین انجام دهی.
5) برای فضای ابری، از داخل برنامه ثبت‌نام/ورود کن. Supabase session را با persistSession نگه می‌دارد.
6) برای انتقال گوشی، از «پشتیبان‌گیری» فایل JSON بگیر و روی گوشی جدید «بازیابی» کن؛ پس از ورود به حساب، همگام‌سازی ابری هم انجام می‌شود.
7) بخش مشاوره بر اساس اطلاعات ثبت‌شده در خود برنامه فایل↔مشتری را امتیازدهی می‌کند و فایل‌های تهاتری را جدا پیشنهاد می‌دهد. این امتیاز، ابزار کمکی است و بررسی واقعی مدارک/ملک را جایگزین نمی‌کند.
8) کتابخانه 20 فصل پایه داخل خود برنامه است و آفلاین کار می‌کند. برای کتاب‌های بیشتر می‌توان بعداً بسته‌های آموزشی را به صورت JSON/HTML دانلود و محلی ذخیره کرد.
