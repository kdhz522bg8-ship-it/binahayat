املاک بینهایت V91 — Cloud + Offline First
1) فایل‌های index.html، sw.js، manifest.webmanifest، .nojekyll و 404.html را در ریشه GitHub Pages قرار بده.
2) setup.sql را فقط در Supabase SQL Editor اجرا کن؛ اگر قبلاً Success گرفته‌ای دوباره اجرا لازم نیست.
3) با اینترنت یک‌بار سایت را باز کن.
4) ثبت‌نام ابری: ایمیل + رمز + تکرار رمز.
5) بعد از اولین ورود آنلاین، ورود آفلاین روی همان گوشی فعال می‌شود.
6) اطلاعات ابتدا روی گوشی ذخیره می‌شود؛ با اتصال اینترنت تلاش می‌کند به Supabase همگام شود.
7) نسخه فعلی، فایل‌های V90 را مبنا گرفته و قابلیت‌های قبلی مشاوره/تهاتر/حسابداری را حفظ می‌کند.
