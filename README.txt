املاک بینهایت - نسخه ابری

1) supabase_setup.sql را در Supabase > SQL Editor اجرا کنید.
2) index.html را جایگزین index.html فعلی در GitHub Pages کنید.
3) با ایمیل و رمز داخل برنامه حساب بسازید.
4) اطلاعات فایل‌ها، مشتری‌ها، حسابداری، قراردادها، برنامه روزانه و مطالعه در جدول app_data ذخیره می‌شود.
5) از داخل برنامه امکان گرفتن فایل پشتیبان JSON هم وجود دارد.

کلید استفاده‌شده در index.html از نوع Publishable است؛ کلید service_role/secret داخل برنامه قرار نگرفته است.
