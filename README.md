# ∞ املاک بینهایت — مربی املاک v3
نسخه PWA آماده میزبانی HTTPS است.
قابلیت‌ها: برنامه اجباری روزانه، درصد عملکرد، مربی و هشدار، فایلینگ با مرور فایل‌ها در بالا، ویلا/باغ‌ویلا/زمین، CRM مشتری، دیوار، کتاب بینهایت، جست‌وجو و ذخیره محلی.
برای Push واقعی روی iPhone باید این نسخه روی HTTPS میزبانی شود و subscription به سرور Push وصل شود. Apple Web Push را برای Home Screen web apps از iOS 16.4 پشتیبانی می‌کند.
